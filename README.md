## عن الموقع

موقع تفاعلي سينمائي يعرض جدول المحاضرات والتمارين والمعامل لطلاب السنة الثانية (Sophomore) بقسم الهندسة الميكانيكية — كلية الهندسة جامعة عين شمس.

الموقع مصمم بتجربة مستخدم مميزة: شاشة مظلمة في البداية، ويسحب المستخدم الحبل ليضيء المصباح ويكشف الجدول.

## المميزات

- **تجربة تفاعلية**: سحب الحبل لتشغيل الإضاءة وكشف الجدول
- **تبديل بين الأقسام**: 6 أقسام منفصلة
- **تصميم سينمائي**: خلفية داكنة، إضاءة دافئة، جزيئات غبار
- **جدول منظم حسب الأيام**: السبت → الأربعاء
- **بطاقات المواد**: اسم المادة كامل، الوقت، النوع، القاعة
- **متجاوب**: يعمل على الموبايل والكمبيوتر
- **أصوات خفيفة** عند التفاعل
- **دعم Reduced Motion**
